Readable programs.
Explicit intent.

Build algorithms, transform data and share readable programs with their own tests.

ZenSigil has its own syntax and interpreter, a command-line tool, and a local playground. Use it for personal projects, community planning, data checks and reviewable workflows. No AI model or API key is needed to run a program.
